# 邪教徒绑架

- 支持 RimWorld 1.5、1.6、1.7；需要 Anomaly 和 Harmony，包名 `RunningBugs.CultistKidnapping`。三版共用源码，1.5/1.6 为 net472，1.7 为 net10.0。
- 只在敌对 Horax 邪教的原版 SkipAbduction 真正折跃出受害者后接管队伍。原版的目标选择、昏迷、记忆和仪式信件保留；玩家仪式和其它邪教仪式不变。
- 在 tick 边界保留同一 Lord，优先由有能力的发起人搬运指定受害者，其余人使用原版 Escort 跟随、防卫当前搬运者。
- 搬运中断、倒地或死亡后选择最近且可预约、到达目标、搬运和离图的队员接替。暂时没有可用搬运者则守住受害者当前位置并继续尝试，不按普通伤亡比例逃跑。受害者清醒时遵守原版搬运限制；死亡或离开该地图后，幸存邪教徒撤离。
- 搬运和离图使用原版 JobDefOf.Kidnap。只有原版已登记受害者且搬运者实际离图才标记成功；原版负责后续心情、关系、通知、世界小人和任务信号，不重复模拟绑架后果。
- 连袭默认启用，每次成功带人出图后随机 3–5 个整数天，再来一波原版 PsychicRitualSiege，指定 SkipAbduction。奴隶被成功绑走也触发；下一波成功可继续。
- 每张地图最多等待一波后续袭击，新的成功不推迟已有较早计时。保留原版难度、场景和事件资格限制；暂时不能执行时每游戏小时重试。关闭连袭取消待执行计时，调整间隔对之后的成功绑架生效，允许 1–30 天整数区间。
- 受害者、搬运者、成功状态、待接管仪式和连袭计时保存到存档。可加入旧存档，移除前结束正在进行的绑架撤离。
- About 提供中英文说明和“由 GPT-6.1 SOL 和 CODEX 制作”署名；Preview.png 由 Python 生成黑底白字。
- PublisherPlus 配置仅上传运行内容与源码/构建文件。直接发布脚本读取同一排除配置，保存条目 ID、校验更新所有权并以 Steam 成功回调及服务端回读确认上传。

1.5、1.6、1.7 全部零警告/错误构建通过。1.7.4995 rev309 三个隔离游戏进程、两次真实读档、30 项检查通过，包含中断/倒地接替、护卫切换、实际离图登记、到期连袭及奴隶续链。1.5 仅参考 API 编译核对；1.6 另核对现有源码/IL，均无对应游戏运行入口，未宣称完成原生实测。
