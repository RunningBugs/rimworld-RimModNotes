# 04 - GD5 对原版机械体的加强 & 流浪者风衣四级详解

> 数据来源：MOD 补丁文件（`Cont/Patches/Patch_VanillaMechanoids*.xml`、`Biotech/Patches/Patch_BiotechMechanoids*.xml`、`Biotech/Patches/Patch_Biotech.xml`、`Odyssey/Patches/Patch_OdysseyMechanoids*.xml`）、C# 源码（`Cont/Source/GD3`），以及游戏原版 Defs 提取对比（提取脚本见 `TMP/extract_vanilla_mechs.py`、`TMP/extract_vanilla_weapons.py`）。
> **重要前提：这些补丁改的是机械体 ThingDef 本体，敌我通用——你的机械体和敌人的机械体享受完全相同的加强。** 玩家独占的优势来自机械师装备（风衣/礼帽）与配方/科技改动。

## 一、全局改动（所有机械体）

| 项目 | 原版 | GD5 |
|---|---|---|
| 工作速度（BaseMechanoid） | 0.5 | **0.85** |
| 心灵敏感度 | 0.5 | **0**（逐个定义覆盖） |
| 失温机制 | 无 | **新增 MechHypothermia**：机械体在寒冷环境会积累"失温"（减速），回到舒适温度后缓慢消退——极地/寒区作战的新弱点 |

## 五、三大 Boss（同时也是风衣升级的经验包）

三者共通：MaxHitPoints 500、EMP 抗性归零、拆解掉 50 精密装甲板、新增**反应装甲**（见下）。

| Boss | 原版 | GD5 |
|---|---|---|
| 魔王 | 钝 0.25 / 锐 0.75，移速 2.4，带宽 5 | 钝 0.70 / 锐 0.90，**热甲 0（弱火！）**，**承伤 ×0.5**，移速 2.7，护盾 1/5，带宽 20；反应装甲 1s/15 次 |
| 战争女皇 | 钝 0.25 / 锐 0.75，血量基数 5.2 | 钝 0.50 / 锐 1.0 / 热甲 2.0，血量基数 3.2（降）但 +500 HP，护盾 1/5，带宽 20；死卫巢扩容（1000 钢存量、每只 20 钢、最多 10 只）；反应装甲 1s/15 次；**玩家所有时新增"自动产死卫"开关与"一键清除死卫"开关** |
| 憎恶毒蜂 | 钝 0.40 / 锐 0.75 | 钝 0.65 / 锐 1.05；**思维压制光环**（55 格内非本派系有机体心灵熵 ×0.01 + 致盲）；反应装甲 **2s**/10 次；**半血时一次性心灵尖啸**：55 格内心灵敏感度 ≥2 的玩家血肉单位强制狂暴；光束光栅炮 5→30 连发、冷却 1.7→1.0、精度全 100% |

**反应装甲（GD_HitArmor，`CompHitArmor`）**：Boss 每次实际掉血后获得一个短时 hediff——**承伤 ×0（完全免伤）**、移速 ×0.9，持续 1~2 秒，有次数上限（10~15 次）；机械师修理可为其充次数。实战意义：**用速射多目标武器骗掉免伤层数，不要用单发大伤害武器撞在免伤上。**

**独眼巨人（Odyssey）**：钝 0.35 / 锐 0.70；光束机枪预热 4s→2s、穿甲 0.5→1.5。

## 七、流浪者的风衣：升级机制与四级加成

### 升级机制（`BlackSuit_Patch.cs` + `CompApparelHediff.cs`）

- 风衣（`Apparel_GD_BlackWindbreaker`）和礼帽（`Apparel_GD_BlackHat`）穿着时每 61 tick 给穿戴者刷新一个"神经元优化"hediff，**等级 = 世界组件 `list_str` 的条目数**。
- `list_str` 的条目来源只有 4 个（**全殖民地共享进度，所有穿风衣的人同等级**）：
  1. 击杀**魔王**（Mech_Diabolus）——一次性
  2. 击杀**战争女皇**（Mech_Warqueen）——一次性
  3. 击杀**憎恶毒蜂**（Mech_Apocriton，机械师召唤的那个原版 Boss）——一次性
  4. **任意一条剧情线通关**（"ScriptFinished"）
- 所以：**4 级 = 三大机械 Boss 全部首杀过；5 级 = 再通关一条剧情线。** 4 级已经是纯战斗能达到的上限。
- 脱掉风衣后 hediff 90 tick（约 1.5 秒）内消失，重新穿上立即恢复——不用担心掉级。

### 风衣四级（level 4）加成明细

风衣 hediff `GD_BlackEnhancer` level 4：

| 属性 | 数值 | 对比原版 |
|---|---|---|
| 机械带宽 | **+48** | 原版带宽只有机械链接 +6、控制芯片 +6/枚，无任何装备提供带宽；+48 等于多养 24 只枪兵或 16 只蜈蚣 |
| 培育速度 | +2（→约 ×3） | 原版只能靠手工技能微增 |
| 修理速度 | +3（→约 ×4） | 同上 |
| 远程修理距离 | +8 | 原版修理芯片满级 19.9 → **27.9** |
| 远程护盾距离 | +8 | 原版护盾芯片满级 19.9 → **27.9** |
| 远程护盾能量 | **+600** | 原版护盾芯片满级 225 → **825**（约 3.7 倍，盾几乎等于给机械体加 825 临时 HP） |
| 全体机械工作速度 | **+100%** | 原版无此加成来源——你的全部工作机械体效率翻倍 |

风衣本体属性：+1.0 移速、锐甲 60%/钝甲 30%/热甲 90%、保暖 42/隔热 36、200 耐久。

### 若同时戴四级礼帽（通常如此）

礼帽 hediff level 4：带宽 **+12**、修理 +0.75、护盾能量 **+150**；礼帽装备属性：+1 培育速度、+25% 贸易。

**风衣+礼帽四级合计**：带宽 **+60**、培育约 ×4、修理约 ×4.75、远程护盾 **975 能量 / 27.9 距离**、远程修理 27.9 距离、全体机械工作 +100%。

### 四级风衣状态下，你的机械体 vs 原版机械体

1. **数量**：+48（或 +60）带宽让机械军团规模数倍于原版机械师；GD5 又把超重型带宽提到 10/20，但你的带宽池照样养得起。
2. **单体质量**：你的机械体与敌方机械体吃同一套 GD5 加强（轻型 0.30/0.55 护甲、重型 0.80/1.10、镰兵 6.15 移速攻速翻倍、蜈蚣子弹减半等）——**这些不是玩家独占**，敌方袭击里的机械体同样硬、同样快。
3. **玩家独占差异**：
   - 远程护盾 825~975 能量（原版最高 225）——关键机械体等于多一条命；
   - 修理/培育数倍速度，军团战损恢复快；
   - 全体工作机械 +100% 工作速度（经济面）；
   - GD5 给的配方福利：焦土怪前移基础科技、助推器 ×2.5 移速光环、辅虫/建造/缝纫/医护技能 14~18 级。
4. **注意代价**：敌人也变硬了（尤其 Boss 的反应装甲免伤、毒蜂的心灵光环与狂暴尖啸、蜈蚣的子弹减伤与 180 连发连锁扫射），且所有机械体（包括你的）新增了**寒冷失温**弱点——寒带作战记得让机械体回屋回暖。

## 八、专题：憎恶毒蜂的"心灵尖啸"应对

机制（`CompApocriton.cs`）：毒蜂血量降到 **≤50%** 时**一次性**触发——以自身为中心 **55 格**内，所有**玩家派系的血肉单位**中，**当前无精神状态且心灵敏感度 ≥2.0** 者强制**狂暴（Berserk）**。机械体、动物以外的血肉单位、中立/敌方单位都不受影响。

**谁会中招**：敏感度 ≥2.0 是很高的门槛——普通小人 1.0、心灵敏感特质 1.4、心灵过敏特质 1.8 都**天然免疫**；只有堆叠型灵能者会过线，例如过敏 1.8 + 增敏植入 +0.25 = 2.05，或再叠加 eltex 装备 / GD5 心灵广播敏化档（+50%，会把 1.4 的也推过线）。

**对策**：
1. 把过线的灵能者放在 55 格以外再打到半血（55 格 ≈ 大半张屏幕，提前走位即可）；
2. 打毒蜂期间**不要开心灵广播敏化档**，改开**钝化档（-50%）可直接把大部分过线者压回 2.0 以下、全体免疫**（若某人敏感度 >4.0，钝化后仍 ≥2.0，需用第三档"拦截归零"压到 0）；
3. 最省事：机械军团主攻（机械体不吃这招），小人全部撤出 55 格；
4. 已狂暴的补救：尖啸只触发一次，狂暴的小人拉开距离、用掩体/烟雾拖时间等其自然结束（或击倒后救治），不会重复触发。

**⚠️ 思滞血清（mind-numb serum）对尖啸无效**（反编译验证）：
- 血清 hediff 本身**不修改心灵敏感度**（Anomaly `Hediffs_Global_Misc.xml:623`，只有 blocksMentalBreaks/思想屏蔽/意识 -5%），小人仍 ≥2.0 会被选中；
- 更致命的是 GD5 调用 `TryStartMentalState(Berserk, reason, true, ...)`（`CompApocriton.cs`），在 1.6 签名中第三个实参是 **`forced=true`**——直接跳过 `MentalBreaksBlocked()` 检查（`Assembly-CSharp.dll` Verse.AI.MentalStateHandler:93），血清（以及非人化 Inhumanized）的 blocksMentalBreaks 对这条路径**完全不生效**。
- 同一检查链里只有"突变体且 preventsMentalBreaks"（食尸鬼等）无条件免疫。

**存档实测（闪毁5-3）**：其他殖民者敏感度 1.0 或 0（两人带 PsychicAbility_Deaf 基因），天然免疫；唯一过线的是**战士-水傲柏**：基础 1.0 + 心灵过敏特质 +0.8 + 心灵敏化装置 +0.25 + 心灵过敏基因（PsychicAbility_Extreme）+0.4，再经**虚空之拥（VoidTouched）×2** = **490%（4.9）**。他不是食尸鬼类突变体，血清和非人化都保不了他；且 4.9 敏感度下心灵广播**钝化档（×0.5 → 2.45）仍 ≥2.0、不够**，必须用**第三档"拦截归零"**（直接压到 0），或让他在毒蜂半血前撤出 55 格。
