# 观感值灵敏度分析:财富/美观/空间/清洁,提升哪个最划算?

> 基于 `model.py` 的 1.6 精确公式做的解析求导 + 有限差分验证(`derivatives.py` 可复算)。

## 1. 求导公式(完整推导)

设 G = 100·g(fW, fB, fS, fC)。g 是**分段线性**(在两个机制区),因子 f 对原始统计量是**分段对数**。

### 1.1 g 对因子的偏导(两个机制区)

**未封顶区**(raw ≤ 5·fS,中大房间):

```
g = (13/80)·Σf + (7/20)·min(f)

∂G/∂fi = 100·[ 13/80 + (7/20)·δ(i=最小因子) ]
       = 16.25            普通因子
       = 51.25            当前最小因子        ← 3.15 倍权重
```

**空间封顶区**(raw > 5·fS,小房间,n≲16):

```
g = (1/4)[(13/80)·Σf + (7/20)·min] + (15/4)·fS

∂G/∂fi = 4.0625          普通因子
       = 12.8125         最小因子(非空间)
       = 379.0625        空间因子            ← 均值项 + 上限项双重作用
       = 387.8125        空间且为最小因子
```

### 1.2 因子对统计量的偏导(链式法则)

F'(x) = 1/max(|x|, 1),于是:

```
∂G/∂W = (∂G/∂fW) · F'(W/1500) / 1500      ← 除数 1500 巨大,财富天然钝
∂G/∂B = (∂G/∂fB) · F'(B/3)   / 3          ← 除数仅 3,美观天然锐
∂G/∂S = (∂G/∂fS) · F'(S/125) / 125
∂G/∂C = 0            (C ≥ 0 时恒为零!)
       = (∂G/∂fC) · F'(1+C/2.5) / 2.5     (C < 0 时)
```

### 1.3 几何耦合(加一格不是只加空间)

```
∂G/∂n = 1.4·(∂G/∂S) + 地板MV·(∂G/∂W) + (∂G/∂B)·[地板美观/d(n) − 美观和·d'(n)/d(n)²]
        └ 空间收益 ┘   └ 地板财富 ┘        └ 美观稀释(负)+ 新格地板美观 ┘
d(n) = 20+n/2 (n≤40, d'=0.5);  n (n>40, d'=1)
```

## 3. 结论(精确版)

**定理(瓶颈原理)**:在未封顶区,g 对因子是线性的,最小因子权重(51.25)是普通因子(16.25)的 **3.15 倍**;在空间封顶区,空间权重(379+)是其他的 **~93 倍**。所以:

> **哪个因子当前最小,提升它就是数学上的最优杠杆——没有例外。**
> (封顶区例外:那里空间压倒一切,因为空间同时出现在均值项和上限项里。)

逐条回答四个统计:

1. **空间**:小房间(n≲16)的唯一答案——每格 +4.3 分,是雕塑的 1.2 倍、财富的 1.6 倍,且成本最低。但一旦逃出封顶区(n≥17),每格收益暴跌到 +0.35,还带来美观稀释(n≳40 时加格甚至是负收益)。**只在逃出封顶区前加格。**

2. **美观**:单位统计量最锐(除数仅 3 vs 财富 1500),且传奇艺术把 800 美观压缩在 1 格内,是**中大房间每银效率最高的杠杆**(约 39~53 分/1000 银)。但对数压缩 F'(x)=1/x 使它边际递减;且在小房间被空间上限封死(此时加雕塑只有 ~3.6 分)。

3. **财富**:单位统计量最钝(每 1000 银仅 +2.7~10.8 分),但它是**大房间(n≳40)的瓶颈因子**——此时权重翻 3.15 倍,+1000 财富 = +34 分。金/银砖地板是最优财富通道(同时加美观,一鱼两吃;金砖每格 703 财富 + 11 美观)。

4. **清洁**:C ≥ 0 时 ∂G/∂C ≡ 0——**清洁对提升观感完全无用**,只需保证不为负。房间脏(C<0)时打扫的边际收益 = (16.25~51.25)·F'(1+C/2.5)/2.5 ≈ 6.5~20.5 分/单位清洁度,非常划算——但这是"止损"不是"提升"。

### 最优升级序列(给定预算)

```
① n≲16:  加格,直到逃出空间封顶区(收益 4.3→0.35 的拐点)
② 之后:   检查四因子谁最小:
   fS 最小 → 加格(中小房间)
   fB 最小 → 加传奇艺术(每银效率最高)
   fW 最小 → 财富物品/金银砖地板(大房间必然走到这一步)
③ C<0 随时优先打扫(止损权重同样 3.15 倍)
④ 每次投入后重新计算瓶颈——边际收益随 F 的对数压缩移动
```

### 边界提醒

 argmin 切换点和封顶区边界是**不可微的折点**,解析导数在该处与实际差分不符
(如 n=16→17 实际 +2.8 而非 +4.3;n=40 附近加格实际为 −0.09)。
跨折点决策请用 `derivatives.py` 的有限差分列,或直接把 `model.py` 当黑盒求值。
