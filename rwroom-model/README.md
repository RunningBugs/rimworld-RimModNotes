# RimWorld 1.6 房间观感值数学模型 & 最小卧室方案

> 临时研究目录，分析完成后可整体删除。
> 数据来源:游戏 1.6.4871 反编译代码 (`RoomStatWorker_*`、`BeautyUtility`、`StatWorker_MarketValue`)
> 与 `Data/Core/Defs` 下的 XML 常数。模型实现见 `model.py`,可重复运行验证。

## 1. 观感值公式(1.6 精确版)

```
fW = F(财富 / 1500)      fB = F(美观 / 3)      fS = F(空间 / 125)
fC = F(1 + min(清洁度, 0) / 2.5)

F(x) = x            (|x| < 1)
     =  1 + ln(x)   (x >= 1)
     = -1 - ln(-x)  (x <= -1)

raw = 0.65 × 平均(fW,fB,fS,fC) + 0.35 × 最小(fW,fB,fS,fC)
cap = fS × 5
raw > cap 时: raw = 0.25×raw + 0.75×cap        ← 小房间被空间上限狠狠压制
观感值 = raw × 100
```

四个子统计:

- **空间** = 站立格×1.4 + 不可站立但可通行格(床/雕塑,PassThroughOnly)×0.5,上限 350
- **美观** = 房间所有格美观之和 ÷ CellCountCurve(n);n≤40 时除数 = 20+0.5n,n>40 时 = n
  → **小房间除数远小于格数,一件高美观物品的美观被"浓缩放大"**,这是小卧室方案的核心
  → 雕塑美观全房间只计一次;墙不计入任何东西(墙不在房间区域内)
- **财富** = 房间内建筑(床/雕塑/门)的 MarketValue + 每格地板 MarketValue
  → **1.6 中品质不影响 MarketValue**:传奇雕塑的财富贡献与普通雕塑相同(钢大雕塑恒为 298)
- **清洁度** ≥ 0 即可(普通地板 = 0 → fC = 1;负值才有惩罚)

心情对照(`SleptInBedroom`,常规小人,持续 1 天):

| 观感值 | 阶段 | 心情 |
|---|---|---|
| <20 | 糟糕 awful | **−2** |
| 20~30 | 乏味 dull | 无思想(±0) |
| ≥30 | 一般 mediocre | +1 |
| ≥40 | 体面 decent | +2 |
| ≥50 | 略显深刻 slightly impressive | +3 |
| ≥65 | 印象深刻 impressive | +4 |
| ≥85 | 非常印象深刻 very impressive | +5 |
| ≥120 | 极其印象深刻 extremely | +6 |
| ≥170 | 难以置信 unbelievably | +7 |
| ≥240 | 不可思议 wondrously | +8 |

关键物品:传奇钢大雕塑 = 美观 100 × 钢1.0 × **品质倍率 8** = **800 美观**,占 1 格。

## 2. 结果:1 床 + 1 传奇钢大雕塑,不同格数的观感值

木地板 + 木床 + 木门(n = 房间总格数,含门格):

| 内部尺寸 | n(含门) | 观感值 | 心情 | 备注 |
|---|---|---|---|---|
| 2×2 | 5 | 32.6 | +1 | 绝对最小;门格若划归隔壁则 28.4 → ±0,**临界** |
| 2×3 | 7 | 41.2 | +2 | 保证 ≥+1 |
| 3×3 | 10 | 54.0 | +3 | 门格划走则 49.7 → +2,临界 |
| **3×4** | **13** | **66.8** | **+4** | 门格划走仍 62.5 → 保证 +3 |
| 3×5 | 16 | 79.6 | +4 | 保证 +4(最小 15 格) |
| 4×4 | 17 | 82.4 | +4 | 保证 +4,余量更大 |
| 4×6 | 25 | 85.2 | +5 | 门格划走 84.9 → +4,**临界** |
| **5×5** | **26** | **85.6** | **+5** | 保证 +5(最小 25 格) |

两条硬结论:

1. **+5(非常印象深刻,85 分)是普通材料地板的天花板**:木地板曲线峰值仅 ~115 分(n≈274),
   永远到不了 +6(120)。原因是清洁度 fC 锁死在 1,美观随格数稀释,空间有 350 上限。
2. 想更高只能靠**财富地板**(美观/财富双高):金砖每格 MV 702.88 + 美观 11:
   - 4×4 金砖(16 格) → **96.2 分,+5**
   - 5×5 金砖(25 格) → **136.7 分,+6**
   - 7×9 金砖(63 格) → **173.2 分,+7**(银砖需 ~233 格,+7 上限同)
   - +8(240) 需要 ~1000+ 金砖格,无实际意义。

## 3. 推荐方案

**目标"最少格数让常规小人心情增加"的甜点方案:**

### 方案 A:极限棺材房(4 格内部,+1 心情)
```
# # D #
# S B #     S=雕塑 B=床(1×2) .=木地板 D=门
# . B #
# # # #
```
2×2 内部 + 1 床 + 1 传奇钢大雕塑。观感 32.6,「一般卧室」+1。
注意:门格归属影响结果(28.4~32.6),最坏情况是"乏味"无心情加成,建议放大一档求稳。

### 方案 B:性价比之王(12 格内部,+4 心情)★推荐
```
# # # D # #
# S . . . #
# B B . . #
# . . . . #
# # # # # #
```
3×4 内部 + 1 床 + 1 传奇钢大雕塑。观感 66.8,「印象深刻卧室」**+4**。
每格效率最高(0.31 心情/格),门格归属无论如何都 ≥+3。

### 方案 C:普通材料封顶(25 格内部,+5 心情)
5×5 内部,床和雕塑随便放(统计与摆放位置无关)。观感 85.2~85.6,
「非常印象深刻卧室」**+5**。这是木地板/石板砖能达到的极限。

### 方案 D:奢侈版(金砖地板)
- 4×4 金砖 → +5;5×5 金砖 → **+6**(132~137 分);7×9 金砖 → **+7**(~173 分)。
- 金砖本身每格 +11 美观 +703 财富,同时抬 fB 和 fW,突破 fC=1 的均值瓶颈。

## 4. 实施注意

- **摆放位置不影响分数**:雕塑美观全房间只计一次(去重),放角落即可,别挡路。
- 床/雕塑格子是 PassThroughOnly:空间只算 0.5(站立格 1.4),但小人可以正常走上去睡觉。
- 房间必须封闭(墙+门+屋顶),且只放**一张床**(两张变营房,心情规则全变负)。
- 保持清洁:脏污/血渍会把清洁度拉到负值直接扣 fC;普通木地板即可,别用草席(−0.1)和土地面。
- 墙不计入任何统计(既不加财富也不加美观),无需为房间观感美化墙壁。
- 模型未经游戏内实测;公式与常数均直接取自 1.6.4871 反编译代码与 XML,边界档(±1 格)请以游戏内房间面板为准。
