# 随机诅咒事件

## 随机池

- 随机诅咒使用世界级、可存档的轮换池。
- 每轮包含 `EatingWithoutTable`、`Research`、`KillAnimals`、`Wounded`、`CutTree` 各一次。
- 每次随机请求从本轮剩余类型中等概率抽取并移除一项。
- 一轮耗尽后，下一次随机请求自动以完整的五种类型开始新一轮。
- 当前是否已有同类型诅咒不影响随机池；新一轮可以抽中仍在激活的类型。
- 指定类型事件不消耗随机池，并继续拒绝当前已激活的类型。

## 重叠实例

- 每个游戏状态以其 `GameCondition.uniqueID` 注册为独立激活来源。
- 同类型限时状态分别保存自己的开始时间和持续时间。
- 一个实例结束时只移除自己的激活来源；只要还有同类型实例，诅咒效果继续生效。
- 仅当最后一个同类型实例结束时发送“诅咒消散”信件。
- 永久模式也可以存在同类型的多个永久展示状态；它们没有倒计时。

## 清除与存档兼容

- “清除所有进行中的诅咒”同时清空旧式激活集合和所有实例激活来源。
- 被清除的限时或永久游戏状态会在下一次状态检查时结束。
- 清除之后新建的实例使用新的 `uniqueID`；旧状态结束时不会误删新实例。
- `randomCursePool` 和 `curseActivations` 随世界存档。
- 旧存档的 `curses` 字段作为兼容激活来源保留；首次加载没有随机池的旧存档时，以当时尚未激活的类型初始化本轮剩余池。
